About Clayfold

Clayfold brings together everyday interface symbols and illustrations of the world around them, from transport and energy to weather and the environment. The icons use a shallow three-quarter view, rounded edges and muted clay colours.

Use Clayfold

Download an icon from the catalog, add it to your app’s assets, and reference it with an image tag. Use the icon font builder to export a color font containing the icons you select.

The JSON catalog lists each icon’s stable ID, label, category and search tags. Use the AI agent guide for file URLs, integration examples and attribution details.

Install with npm

The package includes all 704 WebP icons. Find versioned archives under GitHub Releases.

npm install https://github.com/ZacBytes/clayfold/releases/download/v1.1.0/clayfold-icons-1.1.0.tgz

In a bundler with static image imports, such as Vite, import each icon by its file name.

import bookmark from "clayfold-icons/assets/bookmark.webp";

document.querySelector("#bookmark").src = bookmark;

The catalog is available as clayfold-icons/catalog.json. Use the original artwork license included with the package for attribution.

Country flags

Browse 200 flags covering all 193 UN member states, both observer states, and the Cook Islands, Kosovo, Niue, Taiwan, and Western Sahara. The flag artwork follows the original proportions and emblems with a clay texture and a gentle wave.

File formats

Every icon comes as a transparent 256 × 256 PNG and a lossless WebP. The SVG embeds the PNG in a single self-contained file. It preserves the original lighting and colours, and the artwork inside it remains a bitmap at its original resolution.

Search

Search by name, appearance or purpose. Clayfold ranks matches immediately using icon descriptions and related words, then uses a small language model when available. The model runs in your browser, so search phrases stay on your device.
