About Clayfold

Clayfold brings together everyday interface symbols and illustrations of the world around them, from transport and energy to weather and the environment. The icons use a shallow three-quarter view, rounded edges and muted clay colours.

Use Clayfold

Download an icon from the catalog, add it to your app’s assets, and reference it with an image tag. Use the icon font builder to export a color font containing the icons you select.

The JSON catalog lists each icon’s stable ID, label, category and search tags. Use the AI agent guide for file URLs, integration examples and attribution details.

Install with npm

The package includes all 704 WebP icons. Find versioned archives under GitHub Releases.

npm install https://github.com/ZacBytes/clayfold/releases/download/v1.2.0/clayfold-icons-1.2.0.tgz

Use the same archive URL with pnpm add, yarn add, or bun add.

In a bundler with static image imports, such as Vite, import each icon by its file name.

import bookmark from "clayfold-icons/assets/bookmark.webp";

document.querySelector("#bookmark").src = bookmark;

The catalog is available as clayfold-icons/catalog.json. The package includes the artwork license.

HTML, JavaScript and CSS

Use the hosted WebP, PNG, or SVG URL directly in HTML and CSS. For self-hosting, download the file and point to your own URL.

<img src="https://zacbytes.github.io/clayfold/assets/bookmark.webp"
     width="48" height="48" alt="Bookmark">

<style>
.bookmark {
  background: url("/assets/bookmark.webp") center / contain no-repeat;
  width: 48px;
  height: 48px;
}
</style>

The browser module fills in images by icon ID. Use iconUrl to change an icon dynamically or set a different asset base URL.

<img data-clayfold="bookmark" width="48" height="48" alt="Bookmark">
<script type="module">
  import { renderIcons } from "https://zacbytes.github.io/clayfold/integrations/web.mjs";
  renderIcons();
</script>

Frameworks

Import the WebP for each icon your app uses. The React helper accepts a size, label, and standard image props.

import { Icon } from "clayfold-icons/react";
import bookmark from "clayfold-icons/assets/bookmark.webp";

<Icon src={bookmark} size={48} alt="Bookmark" />
  • Preact and Solid use the same WebP import with <img src={bookmark} width={48} height={48} alt="Bookmark" />.
  • Vue binds the imported WebP with <img :src="bookmark" width="48" height="48" alt="Bookmark">.
  • Svelte uses <img src={bookmark} width={48} height={48} alt="Bookmark" />.
  • Angular and Astro can serve the file from public/ and reference its URL in a normal img tag.
  • React Native can use the downloaded PNG with <Image source={require("./assets/bookmark.png")} style={{ width: 48, height: 48 }} accessible accessibilityLabel="Bookmark" />.

SVG sprite and Node.js

Extract the SVG sprite ZIP and serve the sprite from your app’s own origin. Use the icon ID as the fragment. You can also include the sprite inline once and reference symbols by ID.

<svg width="48" height="48" role="img" aria-label="Bookmark">
  <use href="/assets/clayfold-sprite.svg#bookmark"></use>
</svg>

For server-rendered pages and static site generators, get a standalone SVG string or build a sprite with only your chosen icons.

import { getSvg, getSprite } from "clayfold-icons/static";

const bookmark = getSvg("bookmark");
const sprite = getSprite(["bookmark", "diplomacy"]);

Icon fonts

Download the full color font or build a smaller font with your selection. Keep the CSS and both TTF files together. Use an icon’s CSS class or the ligature in the exported icons.json.

<link rel="stylesheet" href="/assets/clayfold-icons.css">
<span class="clayfold-icons clayfold-icon-bookmark" role="img" aria-label="Bookmark"></span>

Design tools

Download a transparent PNG from an icon’s preview and drop it into Figma or your design tool. For multiple icons, use the full PNG ZIP.

Country flags

Browse 200 flags covering all 193 UN member states, both observer states, and the Cook Islands, Kosovo, Niue, Taiwan, and Western Sahara. The flag artwork follows the original proportions and emblems with a clay texture and a gentle wave.

File formats

Every icon comes as a transparent 256 × 256 PNG and a lossless WebP. The SVG embeds the PNG in a single self-contained file. It preserves the original lighting and colours, and the artwork inside it remains a bitmap at its original resolution.

Search

Search by name, appearance or purpose. Clayfold ranks matches immediately using icon descriptions and related words, then uses a small language model when available. The model runs in your browser, so search phrases stay on your device.
